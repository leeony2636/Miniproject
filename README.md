## 📦 필요한 패키지

프로젝트 실행에 필요한 Python 패키지는 `requirements.txt`에 정리되어 있습니다.

아래 명령어로 한 번에 설치할 수 있습니다.

```bash
pip install -r requirements.txt
```

## 🚀 실행 방법

### 1. 저장소 다운로드

```bash
git clone 저장소주소
```

### 2. 프로젝트 폴더로 이동

```bash
cd Miniproject
```

### 3. 필요한 패키지 설치

```bash
pip install -r requirements.txt
```

### 4. Streamlit 실행

```bash
streamlit run app.py
```
